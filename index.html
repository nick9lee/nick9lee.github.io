Personal Projects

r/Piazza

A distributed version of r/place we built for our distributed systems course — a shared canvas where users place pixel art on a 200x200 grid. The real focus was replication, fault tolerance, data consistency, and synchronization. We ran two proxy servers (one as backup) in front of three main servers, each with its own database, and routed clients randomly to spread the load.

Every server could restart itself automatically. On startup it would look for other live servers and sync its database so replication stayed current. We used Lamport timestamps to keep data consistent across all the replicas. Built with React, Node.js, MongoDB, AWS EC2, Socket.io, and Nginx. Comfortably over-engineered for the number of people who actually used it.

Inline Air Permeability Inspection System

My final-year Capstone, built with two mechanical engineers and another software engineer. We partnered with Roswell Textiles, a leader in nonwoven technologies, to prototype an inline air permeability inspection system. Their existing method only tested small samples, so ours tested continuously through production instead. That let them give clients full data on entire textile rolls — which matters when the material ends up in medical equipment and face masks.

We designed and built the prototype pictured in the top right. A Raspberry Pi read the sensor data and sent it to an Azure Function, which stored it in CosmosDB. The Pi also streamed readings live to a GUI over WebSockets, which you can see in the video. The images show the Pi with our custom circuit board alongside the CAD design.

This one was a nice change of pace. Getting into the warehouse to actually manufacture the thing was the best kind of challenge, and a fitting way to close out my degree.
